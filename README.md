# InmoSmartMobile

# App Movil para Gestión Inmobiliaria


INMOSMART Mobile es una aplicación móvil desarrollada como continuidad del proyecto web INMOSMART. Su objetivo es trasladar las principales funcionalidades del sistema inmobiliario a un entorno móvil, permitiendo a los usuarios acceder a la información de los inmuebles y realizar diferentes operaciones desde su dispositivo.


## Tecnologías

### Backend

* Python
* Django
* Django REST Framework

### Base de datos

* MySQL

### Herramientas de desarrollo

* Git
* GitHub
* Android Studio


## Funcionalidades Principales

* Registro de nuevos usuarios.
* Inicio y cierre de sesión.
* Autenticación mediante credenciales.
* Visualización del catálogo de inmuebles.
* Búsqueda de propiedades mediante filtros combinados.
* Visualización del detalle de cada propiedad.
* Consulta de ubicación y dirección del inmueble.
* Postulación a propiedades disponibles.
* Seguimiento de postulaciones realizadas.
* Modificación de datos personales.
* Cambio de contraseña.
* Formulario de contacto con la inmobiliaria.
* Consulta de información institucional.

## Requisitos no funcionales principales

* Interfaz intuitiva y fácil de utilizar.
* Adaptabilidad a diferentes tamaños y resoluciones de dispositivos Android.
* Buen rendimiento en la carga y consulta de información.
* Protección de los datos mediante mecanismos de autenticación y comunicación segura con el backend.
* Integración con el backend mediante APIs REST desarrolladas con Django REST Framework.
* Persistencia de la información en la base de datos.
* Código organizado y mantenible.

## Flujo general de la aplicación

1. El usuario accede a la aplicación.
2. Se registra o inicia sesión.
3. Una vez autenticado, accede a las funcionalidades disponibles.
4. Consulta el catálogo de propiedades.
5. Utiliza filtros para encontrar inmuebles según sus necesidades.
6. Visualiza el detalle de una propiedad.
7. Consulta la ubicación, requisitos y demás información disponible.
8. Realiza una postulación a una propiedad.
9. Consulta y realiza el seguimiento de sus postulaciones.
10. Puede modificar sus datos personales o cambiar su contraseña.
11. Puede enviar consultas mediante el formulario de contacto.
12. Puede consultar la información institucional de la inmobiliaria.


## Estado del proyecto

Proyecto académico en desarrollo correspondiente a la continuidad del proyecto web INMOSMART.

Actualmente se encuentra en etapa de desarrollo de la aplicación móvil, incorporando progresivamente las funcionalidades definidas en el Product Backlog y organizadas en diferentes sprints.
